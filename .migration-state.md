## Rollback procedure

1. Stop the stack: `docker compose -f docker-compose.yml -f docker-compose.local.yml down`
2. Restore data: `tar -xzf ~/captain-backups/questdb-pre-migration-20260420-1528.tgz -C ~/captain-system`
3. Revert code: `git revert HEAD` (or `git checkout HEAD~1 -- shared/questdb_client.py captain-offline/captain_offline/main.py captain-online/captain_online/main.py captain-command/captain_command/main.py captain-offline/captain_offline/blocks/orchestrator.py`)
4. Restart: `docker compose -f docker-compose.yml -f docker-compose.local.yml up -d --build`
